# Author 工作区

叙述文档和节点画布使用同一个本地 SQLite 数据库。后端使用 Node.js 和 TypeScript，正文编辑器使用 Tiptap。

## 启动

需要 Node.js 24 或更高版本。在项目目录运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3000/ 进入工作区，再点击「叙述层」打开文档列表。文档和画布节点自动保存到 `data/canvas.sqlite`。可用 `PORT` 修改端口，用 `CANVAS_DB` 指定数据库文件。

## 叙述层

- 在叙述层点击「新建文档」，填写名称后可直接在正文的第一个段落写作。顶部「叙述层」可返回文档列表。
- 在左侧目录树添加目录。点击节点打开独立正文，点击有子级的节点旁的「总览」查看该分支。
- 在正文编辑区直接输入文字。选中文字后右键，可以修改字重、颜色、字号或设置链接。
- 顶部齿轮设置文档默认样式、名称和目录编号。段落树里的齿轮可覆盖单个段落的对齐和内边距，也可恢复继承。
- 编辑会自动保存。保存状态显示在页面顶部，也可以按 Ctrl+S 立即保存。

## 画布

- 从顶部「画布」进入，或直接打开 http://127.0.0.1:3000/canvas 。
- 双击空白处添加普通节点，或从节点库选择类型后点击画布放置。
- 拖动节点移动。双击节点或按 F2 改名，按 Delete 删除所选节点。
- 拖动空白处平移，滚轮缩放。点击节点列表可定位节点。

节点类型的默认名称和说明由前后端共用的 `src/model.ts` 定义。
